Cogna Bright Public Website V0.2 — Supabase Connected

This is a separate static public website package for cognabright.com.

Contents:
- index.html
- about.html
- features.html
- families.html
- professionals.html
- contact.html
- privacy.html
- styles.css
- script.js
- assets/

Current status:
- Static public showcase website.
- Responsive header with mobile hamburger menu.
- Register Interest form is connected to Supabase.
- Submissions are stored in public.web_interest_submissions.
- Anonymous visitors can insert only; they cannot select existing submissions.

VentraIP deployment:
1. Upload the contents of this folder to your website public_html directory.
2. Ensure index.html is in the site root.
3. Test desktop, tablet and mobile.
4. Submit a test Register Interest form and verify the row appears in Supabase.
