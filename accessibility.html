Accessibility

Access is part of the work.

The public website is designed to support keyboard navigation, readable resizing, clear structure, visible focus, reduced motion preferences and descriptive form guidance.

Implemented website measures

  • A skip link and semantic page landmarks.
  • Keyboard-operable navigation and form controls with targets of at least 44 by 44 CSS pixels for primary standalone controls.
  • Two-colour visible focus indicators, including a high-contrast mode fallback.
  • Normal text colours tested at 7:1 or better across the website’s primary light backgrounds.
  • Responsive layouts with a readable 70-character text measure, increased paragraph spacing and no fixed body-text sizing.
  • Labels, visible required-field instructions, help text, status announcements and browser-native validation for the enquiry form.
  • Reduced animation when the device requests reduced motion.
  • Meaningful page titles, section headings, link text and language metadata for each translated language name.

Target and verification boundary

The implementation targets Web Content Accessibility Guidelines (WCAG) 2.1 Level AA (the intermediate conformance level) and includes automated regression checks for the measures above and selected WCAG 2.2 Level AAA (the highest conformance level) criteria. This website does not claim full WCAG 2.2 Level AAA conformance, formal accessibility certification or a completed independent conformance audit.

Known manual review

Before production publication, representative users and accessibility specialists should review keyboard order, zoom and reflow, screen-reader announcements, colour contrast in real deployment, error recovery and content comprehension. Hosting responses should also be checked for correct language, caching and error-page behaviour.

Tell us about a barrier

If something prevents you from using this website, use the contact form and describe the page, task, device or assistive technology involved. Do not include personal health information.

Accessibility improvements should be informed by user experience and specialist review.
